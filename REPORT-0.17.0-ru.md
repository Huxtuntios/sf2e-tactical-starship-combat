# Отчёт по экспериментальной сборке 0.17.0

## Статус

Сборка основана на 0.16.1-dev.10 и использует запрошенный номер 0.17.0, но **не является подтверждённым готовым релизом**. Публикация GitHub Release, commit и push не выполнялись. Устанавливайте вручную только в тестовый мир после резервного копирования. Старые архивы не изменены. Манифест сборки содержит адрес будущего GitHub Release, который сейчас не опубликован и не предназначен для установки этой сборки по ссылке.

## Что добавлено к dev.10

- Четыре режима отдельной стрелки курса: None, Text, Emoji, Custom Image; File Picker с предпросмотром, удалением пути и текстовой заменой при ошибке загрузки. Размер, отступ, расположение и прозрачность настраиваются для боя.
- Для существующих объектов карты доступны угол 0–359°, кнопки поворота на 90°, отдельные горизонтальное и вертикальное отражения, независимый сброс поворота/отражений и общий сброс через форму; изменения применяются кнопкой сохранения.
- Автоматическое отражение вычисляется из текущего курса и базового направления изображения. При направлении исходного изображения вправо/влево оно комбинируется с ручным горизонтальным отражением по XOR; при вверх/вниз автоматическое отражение не производится, поскольку текущая игровая модель не содержит вертикального курса. Поворот и отражение не изменяют игровой курс, зоны и координаты.
- У фона независимые угол и отражения: преобразуется только изображение, а не система зон. У старых боёв подставляются стандартные значения без миграции; незнакомые поля сохраняются. Данные записываются в Combat, а право изменения проверяется активным GM. Новые абсолютные изменения разных полей отправляются патчами и последовательно обрабатываются одной очередью Sensor Map на текущем активном GM.
- Добавлены локализация EN/RU, тесты, инструкции, накопительный CHANGELOG и текст для Discord.

## Накопленные изменения после 0.16.0

Включены все изменения экспериментальной цепочки dev.1–dev.10: частичное распознавание базового оборудования корпусов и GM Override; приватный GM-журнал, режимы Chat Announcements и отдельные no-op-проверки; штатная карточка атаки в поддерживаемых путях и отдельный урон; сведения об оружии, некоторые интерактивные описания и наследование типа урона; индивидуальный учёт дронов и ограниченный Drone Block; размещение и инструменты ручного разрешения мин; адресный Boost Battle Station и модификаторы отдельных атак. Подробная история, ограничения и результаты каждой версии — в CHANGELOG и `docs/work-in-progress-0.16.*.md`.

## Проверено

- **Автоматически:** `npm run check` — форматирование, lint, валидация, сборка compendium-паков и 430 тестов; отдельные тесты проверяют нормализацию, ручное/автоматическое отражение, независимость координат и курса, старые данные, неизвестные поля, скрытие данных контактов, права GM, сериализацию параллельных GM-запросов и повтор абсолютной операции в mock-окружении.
- **Локальный браузер:** `npm run test:ui` — 40 сценариев в headless Chromium, включая карту, её изображения, поворот и неизменность рамки нажатия, режимы стрелки и fallback ошибочного файла. Это офлайн-стенд, не Foundry.
- **Вручную и в реальном Foundry для 0.17.0:** не проводилось. Пользователь ранее проверял dev.1; его наблюдения не являются проверкой этой сборки. Совместимость с Foundry 14.370 / SF2e 1.7.0, реальная синхронизация нескольких клиентов, сокеты и смена GM не подтверждены.

## Что остаётся

- Sensor Map: при изображении 8100 × 11700 пользователь наблюдал зависания. Реальное профилирование Foundry отсутствует, секция зон по-прежнему может заменять фон. Оптимизация и причина не подтверждены. Сама карта пока не создаёт отдельные объекты-маркеры дронов и мин, поэтому индивидуальные преобразования этих несуществующих маркеров недоступны.
- Очередь карты не является общей транзакцией со всеми обновлениями боя, актёров и чата. Конкуренция разных подсистем, несколько GM, повторная доставка и failover требуют реального теста. Старый toggle курса не обладает новой гарантией идемпотентности абсолютных визуальных патчей.
- Drone Block поддерживает только определённый одноцелевой путь корабельного оружия по кораблю игроков; Shield Protocol не автоматизирован. Действия Pyrotechnics, Repair, Scramble и три улучшения Drone Console не реализованы полностью. Инструменты мин помогают GM вручную, но не выполняют автоматическое разрешение и нанесение урона. Действия/реакции учитываются вручную.
- Не завершены полный аудит чата и no-op, все интерактивные описания, наследование всех неоднозначных типов урона, все варианты модификаторов станционного урона. GM Override, встроенные улучшения корпусов, приватность журнала и Undo не подтверждены в живом Foundry. Полный план тестирования: `docs/work-in-progress-0.17.0.md`.

Не называйте эту сборку финальной до завершения недостающей механики и проверки в рабочей среде.
