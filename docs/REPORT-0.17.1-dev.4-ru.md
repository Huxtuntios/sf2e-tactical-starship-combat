# 0.17.1-dev.4 — отчёт

Частично реализовано действие Repair Hull для **собственного корабля консоли на активной карте боя**. Проверяются права, уникальность станции и развёрнутого Repair Drone, квалификация Crafting и актуальное состояние. Используется штатная проверка системы, все четыре степени и DC 15/20/30/40, восстановление HP или колющий урон на критическом провале; результат выводится в карточке. Учитываются применимые модификаторы станции. Расход действий и реакций не отслеживается.

При завершённой попытке на корабле сохраняется ограниченный объект `droneRepairReceipts` вместе с результатом; совпадающий ID нельзя применить дважды. Провал тоже сохраняет ID и карточку, но не создаёт записи истории изменения показателей. Это изменение module-owned flags корабля, без миграции и без изменения записей дронов/мин. После 512 идентификаторов новые попытки требуют проверки GM. Новый запрос с новым ID, одновременная работа разных GM и независимые изменения документов не защищены распределённой транзакцией.

**Не реализовано:** Repair Hull для других кораблей или вне боя, Harry Sensors, Intercept Munitions, Drone Shield Protocol, Install Mine, полная автоматизация мин и Pet Drone Shell. Их разрешает GM. PDF не содержит в описании Repair Hull на стр. 193 правила про час/день из пересказа, оно не реализовано. Также PDF указывает Drone Block от уровня оператора, а пересказ — от уровня корабля; оставлено прежнее поведение до уточнения.
