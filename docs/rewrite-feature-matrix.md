# Native-first rewrite: feature matrix

> Аудит T-003 и интеграция проверки T-004 от 2026-11-25. Baseline: `rewrite/native-first-rebuild`, HEAD `fa3bb679ae908c08ce85483a76aa1726b976a3e3`, module 1.3.1. Runtime-исходники, тесты, манифесты, паки и пользовательские изменения в ходе research не изменялись.

## Как читать матрицу

- `СОХРАНЕНО` — текущая реализация соответствует требованию и должна быть перенесена/закрыта регрессионными тестами.
- `ЧАСТИЧНО` — часть поведения есть, но контракт неполон или расходится со спецификацией.
- `НЕТ` — требуемое поведение не найдено.
- `РИСК` — поведение существует, но создаёт существенный технический, правиловой или приватностный риск.
- `УДАЛЕНО НАМЕРЕННО` — не является регрессией; не восстанавливать без нового явного требования.
- `T-004` — нативный контракт проверен по официальной документации и установленным исходникам точной версии; детали и evidence — в API map §12/§16.

### Уточнение пользователя: пункт 8.1

> «пункт 8.1 уже исправлен»

Во вложенном ТЗ нумерации `8.1` нет. Поэтому содержание пунка не угадывается. Строка `U-8.1` ниже фиксирует только заданный пользователем статус: **существующее исправленное поведение**, которое нужно сохранить и покрыть регрессионным тестом, а не реализовать повторно. Конкретный сценарий должен быть сопоставлен родительской сессией по исходному контексту.

### Уточнение пользователя: дальность сенсоров

> Ограничение дальности сенсоров применяется только к игрокам; GM всегда видит полную Sensor Map. Если дальность не задана у NPC-корабля, её нужно добавить из подтверждённого системного источника, без выдуманных значений или множителей.

Это уточнение имеет приоритет над общей формулировкой спецификации и относится к `M-03`, `M-06`, `M-07`, `R-18`, `R-19`, `R-20`.

Дополнительно пользователь предоставил источник `https://2e.aonsrd.com/tactical-starship-combat/ships?sort=level-asc+name-asc&display=full` и предположил, что дальность сенсоров может не влиять на видимость. T-004 подтвердил: Sensor Map видна GM и всем игрокам, Seek работает внутри дальности, а Gunnery может атаковать за её пределами. Поэтому дальность **не является** blanket invisibility rule; boundary/blur — только player UX, detection state по-прежнему управляет приватностью, GM всегда видит всё.
