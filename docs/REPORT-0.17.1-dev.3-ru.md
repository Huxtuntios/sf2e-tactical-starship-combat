# SF2e Tactical Starship Combat 0.17.1-dev.3 — отчёт

Экспериментальная сборка для копии мира. **Это частичное продолжение, не завершение всей задачи.** Подробный отчёт об аудите, конкретные изменённые файлы, состояние до правок, результаты проверок и источники: `docs/work-in-progress-0.17.1-dev.3.md`. Пошаговая живая проверка: `MANUAL-TEST-0.17.1-dev.3-ru.md`.

Исходная база — dev.2, собранная на предыдущем этапе из приложенного архива dev.1, а не отдельно приложенный релиз dev.2. Базовые локальные проверки dev.2: 446 unit/architecture и 41 браузерная фикстура; это не Foundry. Совместимость manifest не повышалась.

Итог dev.3: `npm run check` — 454/454 теста, форматирование, ESLint, проверка содержимого и сборка паков; браузерные фикстуры — 41/41. `npm ci --no-audit --no-fund` выполнен; npm предупредил об install script classic-level. Реальный Foundry не проверен.

## Выполнено

- Закрыты несколько путей неоднозначной адресации мин, дронов и станций в пределах корабля; старые данные не мигрируются и не удаляются.
- Ограниченная защита от **идентичного** повторного socket-пакета для Deploy/Retrieve/установки мины в одном процессе активного GM. Только одинаковые отправитель, ID и тело; кэш до 120 секунд и 512 записей. Новый запрос, смена GM, перезапуск и вытеснение не защищены; не гарантируется exactly-once.
- Безопаснее ручной ремонт: проверка целых неотрицательных значений, повторная проверка прав в очереди, сохранение до очистки инициативы и понятное предупреждение при её отказе. Это не Drone Repair Hull.
- Откат HP/SP запрещён и для старой истории: невозможно достоверно отличить ручную корректировку от последствий урона. Журнал остаётся доступен GM, безопасный ограниченный Undo других операций сохраняется. Изменения формата не внесены.
- Экономика действий и реакций не реализовывалась. Добавлены тесты отказов, повторов, гонок прав и сохранения.

## Осталось ручным или не проверено

Repair Hull, Scramble, Pyrotechnics, три улучшения дронов, детонация, модификации мин, цели и последствия требуют GM; существующие размещение, движение и разрешение мин только частичны. Правила проверены фрагментарно: полного официального текста и системного API для безопасной автоматизации не хватило. Полный сквозной аудит чата, no-op, всех ссылок, модификаторов и реальных Compendium не завершён. Не подтверждены совместимость в Foundry, права/приватность, многоклиентская работа, смена GM и восстановление после сетевых сбоев. Секреты Sensor Map хранить нельзя. Очередь одного GM не является распределённой транзакцией.

Обязательно резервное копирование мира. При ошибке очистки инициативы после ремонта не повторяйте ремонт: GM проверяет инициативу вручную. При неоднозначном сбое сначала проверьте состояние, журнал и чат. ZIP устанавливается вручную; download в manifest — пояснённый адрес ещё не опубликованного релиза. Ничего не публиковалось.
