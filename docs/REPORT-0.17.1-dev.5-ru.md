# 0.17.1-dev.5 — краткий отчёт

Экспериментальная версия: добавлен частичный GM-инструмент Modify Starship Mine. Ведущий подтверждает классовую особенность Modify; на ходу оператора для одной его размещённой мины в зоне корабля выбирается Smart или Targeting. Модификация привязана к мине и проверяется до конца следующего хода оператора. Детонация, исключение цели, спасброски и урон выполняются вручную; Targeting показывает формулу с бонусом Интеллекта, минимум 1. Не заменяет Install Mine.

Требуются уникальные станция/дрон/мина, активный бой, развёрнутый пиротехнический дрон и неизменный определимый порядок инициативы. При изменении порядка, неизвестных старых модификациях и сомнительных сроках выполняется отказ. Поддерживается только одна активная модификация — консервативное ограничение реализации, а не утверждение об общем запрете правил. Повтор того же ID не изменяет состояние повторно; хранилище ограничено 512 ID на мину. Очередь одного GM не гарантирует exactly-once при смене GM и конкурирующих внешних записях. После потери ответа проверяйте состояние перед новым нажатием.

На изменённой мине добавляются необязательные `tscMineModification` и `tscModificationReceipts`, без миграции; остальные поля сохраняются. Запись истёкшего эффекта остаётся метаданными, но не применяется помощником. При перемотке времени GM обязан перепроверить срок. Сохранение, история и чат — отдельные операции. Приватная карточка GM не делает данные мины в flags корабля секретными для имеющих доступ к Actor. В dev.4 уже были свои квитанции Repair Hull; они не менялись и не переиспользуются.

Drone Block оставлен по уровню персонажа согласно PDF и подтверждению пользователя, добавлен регрессионный тест с различными уровнями. Harry Sensors, Intercept Munitions, Drone Shield Protocol/Fetch and Fix, Mine Deployment Shell/Install Mine, автоматическая детонация и Pet Drone Shell/Onboard Pet не реализованы; требуется GM. Учёт действий/реакций не добавлялся.

Исходная dev.4: 473/473 unit/architecture теста и 41/41 фикстура. Итог dev.5: 484/484 unit/architecture теста; 43/43 локальные браузерные фикстуры. Полный список файлов и границы проверки — в `docs/work-in-progress-0.17.1-dev.5.md`. Реальная установка Foundry, SF2e и многопользовательская работа недоступны; сценарии из приложенной инструкции не выполнялись. Сделайте резервную копию, используйте тестовый мир. Релиз не опубликован: адрес загрузки в manifest относится к будущему релизу, ZIP устанавливается вручную.
