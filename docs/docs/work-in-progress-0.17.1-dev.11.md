# 0.17.1-dev.11 — частичная доработка карты и помощника мин

Экспериментальная неопубликованная сборка поверх локальной dev.10. Реальные секреты ей не доверять: ни доступность документов на сервере Foundry, ни многопользовательская приватность не подтверждены.

## Что сделано

- Путь перетаскивания мировых опасностей и размещения мировых кораблей противника/опасностей из каталога ведёт в журнал приватных контактов dev.10. Повторное размещение не сбрасывает состояние. Проверяются доступ игроков к Actor, отсутствие Combatant, активный ведущий, зона и уникальность. Создание Combatant при размещении из каталога убрано, поскольку оно раскрывает Actor. Для опасности доступен её существующий лист.
- Приватный пользовательский контакт без Actor можно создать, переименовать, двигать, удалить и раскрыть. Для всех приватных типов есть выбор состояний: `undetected` и `hidden` не публикуют маркер (даже при включённом показе неизвестных контактов); `observed` после подтверждения публикует только анонимный ключ и зону; `identified` после отдельного подтверждения публикует личность. Перемещение и удаление обновляют анонимную запись. Идентифицированные сведения уже нельзя забрать у клиентов.
- Публичный API постановки опасности по умолчанию использует приватный путь для Sensor Map; публичный путь требует `publicActor: true` и `detection: "identified"`. Это сознательное изменение прежнего контракта API. Новое поле `tscPrivateProjection` есть только у анонимных маркеров; существующее содержимое и прежние приватные записи не мигрируются.
- Старые `zoneInfo.gmNotes` сохранены, но их ввод из редактора и сетевое изменение заблокированы: они на самом деле лежат в общих флагах Combat. Уже сохранённые заметки не становятся секретными. Прочие существующие поля зоны сохраняются.
- Install Mine: редактор предварительно заполняет последний план и передаёт его снимок; новый интерфейс отклоняет устаревшую замену, сохраняя идемпотентность повторов по прежней квитанции. Старые запросы без снимка для совместимости принимаются. Не добавлен учёт действий/реакций. Код Toolbelt и Drone Block не менялся.

## Незавершено и ограничения

Install Mine **по-прежнему только заметка GM**: нет учёта мин на борту, системной проверки Mine Exocortex/известных модов, применения и истечения, сопоставления с физической миной, переноса на карту. Это не полностью играбельный цикл. Tech Core с. 184 описывает Modify мин внутри ещё не развёрнутого дрона; отдельное Deploy Starship Mine описано на с. 193. Поэтому подготовка не создаёт развёрнутую мину на карте. Персональные моды механика не приравниваются к Smart/Targeting. GM проверяет все условия, мины, эффекты и сроки вручную. План хранится в Actor flags, не является секретом.

Приватные контакты не участвуют в целеуказании и автоматизации опасностей, анонимный маркер не заменяет настоящий Actor. Нет выбора нового Actor прямо из редактора карты: используются перетаскивание и каталог. Создание и редактирование полноценной мины/связи с дроном на карте отсутствуют. `hidden` сейчас намеренно консервативнее старой карты. Состояние уже публичных объектов не засекречивается задним числом. Проверка ограничена путями добавления, а не всеми интерфейсами; сторонние модули, токены, старые сообщения, общий журнал и Actor, история, поиск, и иные потоки могут раскрывать данные. Права могут измениться после постановки.

Обновление анонимного маркера и приватного журнала не атомарно. При обрыве возможны устаревшие маркеры; проверьте оба документа, повторите прежнюю операцию или исправьте вручную. Очередь одного активного GM не является распределённой транзакцией; смена GM, параллельные изменения извне и потеря соединения не дают exactly-once. При неудаче после полного раскрытия нельзя отменить уже переданную информацию. После уменьшения числа зон положение приватного контакта требуется проверить вручную.

Совместимость старых данных проверена лишь на локальных моках. Новых миграций нет; существующие `droneRepairReceipts`, `tscMineModification`, `tscModificationReceipts` и старые поля не удалялись. Реальные миры, сетевой слой и интеграция с Toolbelt не проверены. Требования совместимости manifest не повышены. Исходный manifest и ручной установочный ZIP не содержат ссылок автообновления; обычный release-скрипт при отдельном запуске формирует ссылки для ещё не опубликованного релиза.
