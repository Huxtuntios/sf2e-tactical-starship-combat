## Sensor Map

Новый NPC-корабль мира, перетаскиваемый на карту активным GM, попадает в отдельный JournalEntry без папки с default ownership NONE. Состояние `undetected` — внутренний эквивалент «необнаруженного»; контакт отображается только в контексте GM. В Combat flags и module socket при приватном добавлении/перемещении/удалении UUID не передаётся. Перед размещением проверяются Actor-документ мира, роль npc, отсутствие доступа LIMITED у игроков, отсутствие Combatant и существующей публичной записи. GM может передвинуть, удалить и явно раскрыть контакт как identified. Предупреждение перед раскрытием сообщает о необратимой передаче имени, UUID и позиции. Повторное добавление не сбрасывает состояние; после сбоя очистки приватного журнала повторное раскрытие не создаёт дубликат в Combat в тестовой модели.

**Не завершено:** промежуточные уровни обнаружения из приватного состояния, целеуказание, автоматические игровые действия и полная интеграция всех интерфейсов. Эта реализация не гарантирует скрытия в документах, других модулях, старых сообщениях, токенах, кэше или при изменении прав после размещения. Прежние `zoneInfo.gmNotes` остаются в общих Combat flags и не являются секретными. Другие действия на листе частного NPC могут раскрыть его через чат или сокет; сквозная проверка всех путей не завершена. Приватность журналов и сетевых обновлений в настоящем Foundry, переключение GM и многопользовательские гонки **не проверены**. Для настоящих секретов пока не использовать. Нельзя задним числом скрыть уже общие данные. Очередь процесса GM не распределённая транзакция. Компенсация после частичного раскрытия не отменяет уже переданные сведения.

## Install Mine

Источник: приложенный Tech Core, печатные с. 36–37 и 184. Личные модификации механика не тождественны модификациям развёрнутых звёздных мин. Поэтому добавлен помощник подготовки: ведущий вручную подтверждает Mine Exocortex, реальные мины, известные модификации, применимость и срок; указывает до четырёх уникальных обозначений и текст модификации. Проверяются действующая станция и оператор, ровно один установленный Mine Deployment Shell, один однозначный Pyrotechnics Drone на станции и его неразвёрнутое состояние. Записываются только заметки в `tscInstallMinePlan` и отдельные квитанции `tscInstallMineReceipts` конкретного дрона; есть список в листе и карточка ведущему. Повторы одного ID не создают повторной записи или карточки; старый запрос не перезаписывает новый план.

**Не завершено:** учёт реальных мин на борту, автоматическая проверка class feature/известных модов, фактическое применение, перенесение модификаций на развёрнутые мины и истечение срока. GM самостоятельно применяет эффекты и проверяет срок; сохранённая заметка не подтверждает актуальности. Заметки находятся в Actor flags корабля и не являются секретным хранилищем; игрок с доступом к Actor может их прочесть. Другие квитанции не переиспользуются. Изменения — дополнительные необязательные поля, без автоматической миграции; совместимость со старыми данными проверена локальными тестами, но не настоящим миром.
