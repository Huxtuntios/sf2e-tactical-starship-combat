# 0.14.0 — GitHub-ready release

Repository and release preparation for **Huxtuntios/sf2e-tactical-starship-combat**.

## Changes / Изменения

- Reorganized the public project presentation: English README, Russian README, installation instructions, contribution conventions, bug templates and GitHub Desktop release guide.
- Unified JavaScript, styles and documentation formatting with Prettier; Python extraction tools use Black. Removed outdated version labels from runtime comments.
- Replaced the Bash release packager with a portable Node.js builder. Runtime archives contain compiled compendiums and have `module.json` at the ZIP root.
- Added GitHub CI and release workflows, checksum generation and validation of matching manifest/package/tag versions.
- Added a portable Chromium UI test runner and removed developer-specific paths from optional content extraction tools.
- Fixed a corrupted Russian `Успех` heading in ship ability parsing.
- Preserved the existing gameplay features, EN/RU content and ORC licensing. No intentional combat-rule changes in this release.

## Installation / Установка

Publish GitHub Release **v0.14.0** from the prepared commit. The **Release** workflow builds and attaches `module.json`, `module.zip` and `SHA256SUMS.txt` automatically. No manual asset upload is needed for normal mutable releases. Do not install GitHub's automatically generated Source code archive.

Pinned manifest (also works for a published prerelease):

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/download/v0.14.0/module.json
```

Stable channel (only after a non-prerelease release exists):

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/latest/download/module.json
```

**Back up your world before updating.** Requires Foundry VTT v14 (minimum 14.361) and SF2e 1.6+. Automated Node and local Chromium checks do not certify a live Foundry world or multi-client behavior. Run the manual test plan before marking the release stable.

**Перед обновлением сделайте резервную копию мира.** Автотесты не заменяют проверку в запущенном Foundry с ведущим и игроком. Ссылки работают только после публикации репозитория и вложений релиза.
