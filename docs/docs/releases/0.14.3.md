# 0.14.3

- Все три спасброска — Стойкость, Рефлекс и Воля — доступны через адаптер корабельных характеристик, добавленный в 0.14.2.
- При активном Toolbelt добавлены кнопки «Урон через щиты» и «Напрямую в корпус».
- Обычные кнопки положительного урона для кораблей используют корабельный движок; поддерживаются множители и числовая поправка через Shift.
- Типы урона сохраняются; Твёрдость и переход щиты/корпус не дублируются при нескольких типах.
- Добавлены защита от повторного списания и проверка прав на стороне ведущего.
- Обычные акторы и лечение не изменены. Для новых карточек атак модуля исключены дублирующие кнопки.

После обновления перезагрузите мир. Не применяйте старые карточки атак двумя разными способами. Для невычисленного продолжительного урона и раздельного урона по области используйте ручное применение. Личный «Блок щитом» не управляет щитами корабля.
