# 1.2.0

Usability release for the tactical starship combat creation window. It simplifies the startup workflow without changing combat mechanics, the Sensor Map, or the crew/station interfaces. The full categorized history is in [CHANGELOG.md](https://github.com/Huxtuntios/sf2e-tactical-starship-combat/blob/main/CHANGELOG.md).

Highlights:

- Pre-combat review and validation moved into a separate review dialog with a dedicated open button; a new client setting "Auto-open the pre-combat review" controls automatic display. Validation and the two-step confirmation remain active regardless of the setting, and the review can always be opened manually. Returning to editing keeps the draft.
- The actor browser is collapsed into an expandable section, and the duplicated per-ship crew/station editing controls were removed from the creation window. Each player ship shows a compact crew/station summary with a button to the existing Crew Manager; crews stay editable during combat. Initiative participation, station assignments and preset compatibility are preserved.
- One primary scrolling area replaces the nested scroll containers; the window is resizable and gained a maximize/restore toggle, with a larger default size for encounters with several starships.
- "Use existing world Actor instead of a fresh copy" defaults to enabled for new eligible entries. Presets keep an explicitly saved value (including `false`); older presets without the flag use the new default. Ineligible entries still cannot reuse, and reusing leaves the original Actor untouched.

Compatibility declarations are unchanged: Foundry v14 (minimum `14.361`, verified `14`, maximum `14`); SF2e `1.6.0+` (verified `1.6.1`); PF2e `8.6.0+` (verified `8.6.1`) with active SF2e Anachronism `2.4.0+`. The module ID, pack names and document IDs are unchanged; no world migration is required. No action/reaction accounting is added. The Sensor Map is completely unmodified.

## Installation after an authorized publication

Manifest URL (stable channel, works only after a regular non-prerelease release is published):

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/latest/download/module.json
```

Version-specific manifest:

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/download/v1.2.0/module.json
```

For manual installation, extract `module.zip` into `Data/modules/sf2e-tactical-starship-combat/` so that `module.json` lies directly in that folder. Back up the world first. GitHub's automatic source archives are not installable module packages.
