# 1.0.0

First stable release. It consolidates the published `v0.16.0`, the `0.17.0` build, the `0.17.1-dev.1–13` experimental series (published as pre-release `v0.17.1-dev.13`), the reliability follow-up (PR #12/#13), the combat-wizard improvements (PR #14) and the post-wizard reality-check audit (PR #15). The full categorized history is in [CHANGELOG.md](../../CHANGELOG.md).

Highlights:

- Combat wizard with write-free drafts until confirmation, independent NPC/hazard instances and checked compensating cleanup; station actions scoped to the current encounter, preserved when retained ships are explicitly reused.
- Sensor Map: GM add-object window with private contact staging in a GM-only journal, confirmed and recoverable reveal, independent persistent Actor copies per placement, private/anonymous initiative controls, per-object course-arrow formats and auto-mirror overrides, retained background DOM with a 4096 px PNG display copy for giant images.
- Drone Console and mines: individual tracked drones, GM-confirmed Drone Block from native Strike cards, manual-only Drone Shield Protocol path, Install Mine stock and Deploy Starship Mine with a dedicated Hazard Actor and linked map contact.
- Native SF2e check dialogs and attack cards on supported paths; character-sheet station claim/release.
- Reliability: bounded socket waits, Toolbelt critical evidence from the stored roll degree (not manual ×2/×3), guarded Undo recovery with persisted intent/receipt, staged reveal recovery, Draft/queue concurrency guards, preserved NPC damage components and nonlethal propagation.
- Packaging: only declared compiled packs, LevelDB integrity checks, post-upload asset verification.

Compatibility declarations are unchanged: Foundry v14 (minimum `14.361`, verified `14`, maximum `14`); SF2e `1.6.0+` (verified `1.6.1`); PF2e `8.6.0+` (verified `8.6.1`) with active SF2e Anachronism `2.4.0+`. The module ID, pack names and document IDs are unchanged; no world migration is required. No action/reaction accounting is added.

## Installation after an authorized publication

Manifest URL (stable channel, works only after a regular non-prerelease release is published):

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/latest/download/module.json
```

Version-specific manifest:

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/download/v1.0.0/module.json
```

For manual installation, extract `module.zip` into `Data/modules/sf2e-tactical-starship-combat/` so that `module.json` lies directly in that folder. Back up the world first. GitHub's automatic source archives are not installable module packages.
