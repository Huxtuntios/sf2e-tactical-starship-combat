# 1.4.0

Unified GM-controlled effects, native crew application and durable ship persistent damage. This is release preparation on `feat/v1.4.0-starship-effects`, not a published release.

## Highlights

- One manager from Starship Sheet and GM Sensor Map public/private detail, configuration followed by a separate target confirmation, Entire Starship default, explicit target union and real installed station/action/weapon/registered crew catalogs.
- Actual native-stacked numeric modifiers, check/DC domains, contextual attacks/MAP preview, supported condition/state gates and exact linked native crew Items. Incompatible mechanics and rejected native recipients are reported, not represented as display-only success.
- Optional GM-only Ignore Target Immunities, off by default and scoped to one application's effect-immunity check. Affected-by restrictions, stacking, actual immunity data and later damage IWR remain intact.
- Native persistent dice, strongest same-type suppression, simultaneous multi-type ship damage through IWR/Hardness/shields/hull, explicit GM packet application followed by recovery, reload-safe receipts and independent crew recipients. Exact row deletion is distinct from same-type ship recovery.
- Actual ordinary ship turn-end processing, or one approved ship-level end-of-round fallback when the ship has no ordinary turn. Crew and compromised hull-integrity turns do not create extra ticks. Outside-combat processing uses current world time.
- Full EN/RU controls, target/parameter summaries, statuses, errors, immunity explanations and README workflows. Existing wizard, detection policy, crew interfaces, physical station repair, native attack/MAP and manual Drone Shield Protocol paths are preserved.

## Compatibility and boundaries

Manifest declarations are unchanged: Foundry v14 (minimum `14.361`, verified `14`, maximum `14`); SF2e `1.6.0+` (verified `1.6.1`); PF2e `8.6.0+` (verified `8.6.1`) with active SF2e Anachronism `2.4.0+`. Module/pack/document IDs are unchanged; no world conversion, translation pack, system-file modification or new dependency is introduced.

Native contracts were reviewed in installed Foundry **14.370 / SF2e 1.7.1 / PF2e 8.7.1**, with Anachronism **2.5.1** and Toolbelt **3.62.0** available locally. Source review and mocks are not live compatibility certification. Native ship condition rules require verified supported modifiers; arbitrary native/custom non-modifier conditions and non-Strike NPC abilities stay manual. There is no independent weapon-defense statistic to select. Entire Starship does not automatically apply to crew. Normal native crew persistent damage remains the system's mechanism.
