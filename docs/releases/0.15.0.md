# 0.15.0

- Добавлена поддержка PF2e 8.6.0+ с активным SF2e Anachronism 2.4.0+ на Foundry v14.
- Для PF2e поставляются отдельные компендиумы; SF2e-паки и их UUID сохранены.
- Адаптированы системные флаги урона и инициативы, картинки действий и угроз, поиск установленных улучшений и состояний.
- Проверяется наличие Anachronism и навыков Computers/Piloting; без них корабельная автоматизация в PF2e не запускается.

В PF2e включите оба модуля и перезагрузите мир. Используйте папку компендиумов Tactical Starship Combat (PF2e). Anachronism не требуется в мире SF2e. Перенос мира между системами не выполняется.
