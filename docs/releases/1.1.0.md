# 1.1.0

Post-1.0.0 reliability and usability release. It consolidates the scene-controls fix, Toolbelt layout correction, guarded damage undo, per-ship action queues, Draft commit coordination, station-cleanup guards, toggle buttons and auto-mirror from heading. The full categorized history is in [CHANGELOG.md](https://github.com/Huxtuntios/sf2e-tactical-starship-combat/blob/main/CHANGELOG.md).

Highlights:

- Scene-control buttons (Sensor Map, Station HUD, Start Combat, Toolbox) registered during `init` so Foundry 14.370 shows them; pressing a button again closes its window instead of stacking another.
- Auto-mirroring works out of the box: new starship objects take base direction from the ship sheet heading; the orientation menu offers left/right (rotation and flips kept) and preserves saved direction until explicitly changed; orientation is remembered per Actor and inherited by copies.
- Toolbelt damage row wraps ship controls onto their own line; a GM-only "Undo damage" button on damage chat messages returns exactly the shields/hull removed, with guards against critical states, changed ships and double undo.
- The general history Undo restore action is removed (it could not reliably reverse changes); the GM-only history journal remains as a read-only audit log.
- Weapon Strikes open only the native system roll dialog by default; the extra situational-modifier form is behind a world setting (off by default).
- Drone Block from sheet/HUD is soft-automated: player/GM confirms, drone returns aboard, cooldown starts, resistance reported for GM to apply.
- Action execution serialized per ship; Draft commits rebase disjoint edits and refuse overlapping ones; success hooks run outside the write-lock; rebase refuses to restore concurrently deleted entries.
- Removing a drone console removes bound drones and mine entries, refused while armed mines or failed cleanup remain.

Compatibility declarations are unchanged: Foundry v14 (minimum `14.361`, verified `14`, maximum `14`); SF2e `1.6.0+` (verified `1.6.1`); PF2e `8.6.0+` (verified `8.6.1`) with active SF2e Anachronism `2.4.0+`. The module ID, pack names and document IDs are unchanged; no world migration is required. No action/reaction accounting is added.

## Installation after an authorized publication

Manifest URL (stable channel, works only after a regular non-prerelease release is published):

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/latest/download/module.json
```

Version-specific manifest:

```text
https://github.com/Huxtuntios/sf2e-tactical-starship-combat/releases/download/v1.1.0/module.json
```

For manual installation, extract `module.zip` into `Data/modules/sf2e-tactical-starship-combat/` so that `module.json` lies directly in that folder. Back up the world first. GitHub's automatic source archives are not installable module packages.
