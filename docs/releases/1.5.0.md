## Included behavior

- Unified GM-controlled manual effects with explicit whole-ship, mechanic, station, action, weapon and crew scopes.
- Native crew condition/effect Items for supported recipients, stable operation IDs, partial rejection reporting and synchronized removal.
- Persistent-damage staging in the existing action Draft, strongest expected-value selection per damage type, native dice, durable receipts, explicit GM application and ordered recovery.
- One ordinary ship-turn interval, with one end-of-round fallback when the ship has no ordinary turn; crew turns and compromised hull-integrity turns do not add ticks.
- A combined Effect Manager and localized ApplicationV2 target dialog, retaining operational/destroyed controls and native valued conditions.
- Additive public API methods: `applyManualEffect`, `removeManualEffect`, `getEffectTargetCatalog`, `processPersistentDamage`, `applyPersistentDamage`, `recoverPersistentDamage`, `openEffectManager`.
- Preserved native-first targeting, hazard statistics/saves, plasma multi-target flow, Sensor Map range/detection/placement, chat-card outcomes and native condition management.
- No general Undo or change-history UI. The existing narrow guarded Toolbelt per-application damage undo remains.

The module ID, pack names, document IDs and compatibility declarations are unchanged. New effect/receipt fields are optional and additive; no destructive world migration or `DATA_VERSION` increase is introduced.

## Installation

### Verified local artifact

1. Back up the target world and disable the currently installed module copy.
2. Use the locally built `dist/module.zip`.
3. Extract it into `Data/modules/sf2e-tactical-starship-combat/` so that `module.json` is directly inside that directory.
4. Enable **SF2e Tactical Starship Combat**, reload the world and verify the loaded version is `1.5.0`.
5. Run the pending live checklist below before campaign use.

GitHub automatic source-code archives are development sources, not installable module packages.
