# 1.3.1

Targeted correction for player starship weapon attacks: the actual station operator's native weapon-specific proficiency now contributes to the actual d20 modifier, alongside that character's Dexterity. Ship tracking, station modifiers and MAP remain separate; NPC statblock attacks and deferred damage are preserved.

## Highlights

- Native category, group, equivalent base weapon and special proficiency definitions determine the applicable rank. Missing category data no longer borrows martial or defaults to Trained. Existing valid category ranks already worked; the defect was incomplete weapon-specific resolution and unsafe fallback.
- The authoritative weapon assignment resolves the operator before permissions and MAP. Proficiency changes, weapon edits and reassignment affect the next attack even when the original request names an earlier operator. Unoccupied assigned stations never borrow a character.
- A transient native ship weapon supplies proficiency and applicable modifiers; no handheld weapon's complete attack statistic is copied or inventory Item persisted. Native conditional options, weapon-dependent Rule Elements and modifier adjustments remain intact.
- Distinct native attack identifiers preserve the correct receipt when otherwise identical rolls are rerolled. The system's own reroll dialog, separate damage roll and duplicate-application protection remain in use.

## Compatibility and implementation boundary

Declarations are unchanged: Foundry v14 (minimum `14.361`, verified `14`, maximum `14`); SF2e `1.6.0+` (verified `1.6.1`); PF2e `8.6.0+` (verified `8.6.1`) with active SF2e Anachronism `2.4.0+`. Module and pack/document IDs are unchanged; no world migration is required. No new dependencies or UI redesign are introduced.

The adapter uses the internal character `prepareStrike` contract, source-reviewed in SF2e `1.7.1` and PF2e `8.7.1`, followed by native `CheckModifier` / `Check.roll`. Changes to that internal contract require revalidation; the module refuses an attack if native proficiency cannot be resolved rather than guessing a rank. The older manifest-verified system versions were not live-recertified by this work.
