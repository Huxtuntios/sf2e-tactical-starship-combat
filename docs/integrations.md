# Integrations

- **HoloDock** — optional. Field ownership: tactical module owns `hp, sp, ac, speed, sensorRange, compromised, wrecked, heading, stations, combatState`; HoloDock owns `profile, image, loadout, components, dashboard, pins`. The bridge is read-only with respect to tactical data: the _Open HoloDock_ button calls only `open()` from `game.holodock` or the module API, and no HoloDock data is imported or written to the ship. HoloDock 1.0.1 does not expose `openDashboard`, `openProfile`, or `openShip`.
- **Aztec's Engines of War** — vehicles carrying `flags.pf2e-aztecs-siege.isSiegeWeapon` cannot be converted to starships; the flag on other actor types does not trigger Aztec protection, and no HUD is added to ordinary vehicles.
- **Causodes Ship Combat** — separate actor sub-types and flags; nothing is intercepted. A permanent warning is shown to the GM when it is active (setting _Causodes conflict handling_). Do not run both engines on one ship/encounter.
- **SF2e Anachronism (PF2e only)** — required at runtime. PF2e must satisfy both this module's minimum and the active Anachronism module's declared PF2e compatibility; Computers and Piloting must be registered after init.
