# Отчёт: 0.17.1-dev.6

Это экспериментальная неопубликованная сборка для проверки на копии мира. Основа — dev.5. Правила сверены с доступным PDF Tech Core; архив Нэфиса в сессии отсутствовал. До работы прошли 484 автоматических теста и 43 браузерные фикстуры.

Добавлен **частичный GM-помощник**, а не автоматическая детонация: корабли на сенсорной карте в зоне мины перечисляются в диалоге и приватной карточке; при действующем Smart можно выбрать не более одного исключения. Несовпадающие/неоднозначные данные и изменения при открытом диалоге вызывают отказ. Ведущий вручную проверяет полноту карты, бросает спасброски, применяет урон и исключение и отмечает мину взорванной. Существующие квитанции, срок действия модификаций, Repair Hull и Drone Block сохранены.

Harry Sensors, Intercept Munitions, Drone Shield Protocol и Fetch and Fix, Install Mine, автоматическая детонация и Onboard Pet не реализованы; разрешайте вручную. Targeting сохраняет ручную формулу, а не рассчитанный результат. Действия/реакции не подсчитываются. Данные и формат существующих записей не изменены, миграция не добавлена. Совместимость со старыми сохранениями в настоящем Foundry не проверена.

Проверки после изменений: `npm run check` — 493 автоматических теста, включая девять новых; Prettier, ESLint, валидация контента и сборка паков. `CHROMIUM_PATH=/usr/local/bin/chromium npm run test:ui` — 45/45 локальных браузерных фикстур. Реальный Foundry и многопользовательские сценарии **не проверены**. Подробные ограничения и список файлов — `docs/work-in-progress-0.17.1-dev.6.md`; невыполненный чек-лист — `MANUAL-TEST-0.17.1-dev.6-ru.md`.

GM-карточка не гарантирует приватности флагов, а блокировка диалога действует только в одном клиенте. Разные GM, новый запрос после закрытия или сбой соединения могут привести к повторной карточке; очередь одного GM не обеспечивает распределённого exactly-once. Ведущий должен сверять состояние и чат перед ручным применением и повтором. Manifest сохраняет старые декларации совместимости, а ссылка dev.6 указывает на ещё не опубликованный релиз; прилагаемый установочный ZIP предназначен для ручной установки. Commit, push и публикация не выполнялись.
