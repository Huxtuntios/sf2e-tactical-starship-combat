# Отчёт 0.17.1-dev.7

Экспериментальная неопубликованная версия; сначала резервная копия и отдельный тестовый мир. Установочный ZIP устанавливается вручную, ссылка в manifest ведёт на ещё не опубликованный релиз.

Добавлены частичные помощники: типизированный бросок и Reflex для отмеченных на карте целей мины с ручным резервным вводом и предварительным расчётом до защит; Will и текст результата Harry Sensors; подтверждаемая GM запись ручного Intercept с восстановлением при Retrieve. Применение урона, закрытие мины, применение условий и штраф к атаке остаются ручными. Автоматических реакций, расхода действий, Shield Protocol, Fetch and Fix, Install Mine и Onboard Pet нет.

Добавляются необязательные поля Intercept на отдельном дроне, без миграции. Дубликаты ограниченно защищены; при сбое и смене ведущего нет распределённой транзакции или гарантии единственного выполнения. Активный ведущий обязан проверить карточку и состояние до повторного действия. Приватный чат не скрывает Actor/Combat flags.

`npm run check` — 512/512 unit/architecture-тестов, форматирование, ESLint, проверка содержимого и сборка паков; `CHROMIUM_PATH=/usr/local/bin/chromium npm run test:ui` — 47/47 браузерных фикстур. Реальная установка Foundry и многопользовательская игра не проверены; инструкция находится в `MANUAL-TEST-0.17.1-dev.7-ru.md`. Полный перечень изменений, оснований правил и ограничений — `docs/work-in-progress-0.17.1-dev.7.md`.
