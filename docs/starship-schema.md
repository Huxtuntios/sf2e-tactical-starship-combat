# Starship data schema (`flags.sf2e-tactical-starship-combat.starship`)

Marker: `isStarship: true` is **required** — ordinary vehicles/NPCs are never treated as starships. `dataVersion` (currently `1`) drives migrations.

| Field                                                                                   | Type                                                                                             | Notes                                                                                                                                                                                                                                                                   |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `role`                                                                                  | `player\|npc\|ally\|neutral\|autonomous\|living`                                                 | `player` ⇒ vehicle actor, no combatant of its own                                                                                                                                                                                                                       |
| `level`, `frame`, `size`                                                                | int, frame id, size                                                                              | frame is only a template                                                                                                                                                                                                                                                |
| `speed`, `sensorRange`                                                                  | int (zones)                                                                                      | effective values add helmed bonuses/effects (`computeShipStats`)                                                                                                                                                                                                        |
| `ac`, `fort`, `reflex`, `will`, `perception`                                            | int                                                                                              | Fortitude/Reflex/Will/Perception **modifiers**; DC = 10 + mod                                                                                                                                                                                                           |
| `sp {value,max}`                                                                        | Shield Points                                                                                    | module-owned                                                                                                                                                                                                                                                            |
| Hull Points                                                                             | `system.attributes.hp`                                                                           | **owned by the system** (token bars, XP, `dead` automation); mirrored into the read model                                                                                                                                                                               |
| `compromised`, `wrecked`                                                                | int                                                                                              | `compromised ≥ 10` ⇒ destroyed                                                                                                                                                                                                                                          |
| `inoperable`, `offKilter`, `destroyed`                                                  | bool                                                                                             |                                                                                                                                                                                                                                                                         |
| `heading`                                                                               | `left\|right`                                                                                    | source of truth in combat is the sensor-map object; the flag mirrors it                                                                                                                                                                                                 |
| `immunities`, `resistances{type:n}`, `weaknesses{type:n}`, `hardness`                   |                                                                                                  | defaults to the _starship immunities_ list                                                                                                                                                                                                                              |
| `stations[]`                                                                            | see station schema                                                                               |                                                                                                                                                                                                                                                                         |
| `crew[]`                                                                                | `{actorUuid,name,userId,role,stationId,ready}`                                                   | roles `captain\|crew\|observer`, 1–6 active members                                                                                                                                                                                                                     |
| `weapons[]`                                                                             | `{id,weaponRef,name,die,damageType,range,traits[],category,stationId}`                           | custom weapons allowed                                                                                                                                                                                                                                                  |
| `upgrades[]`, `expansionBays[]`                                                         | `{id,ref,variant,stationId,name,station,level,override}` / `{id,name}`                           | 0.9.1: the only list of installed upgrades. `ref` = catalog id, `variant` = grade key or null, `stationId` = battle station (null = ship level / unassigned), `override` = GM installed it beyond the rules. `stations[].upgrades` is legacy and folded into this list. |
| `effects[]`                                                                             | `{id,slug,label,modifiers[{selector,type,value}],conditions[],expire{round,turn},station,rider}` |                                                                                                                                                                                                                                                                         |
| `frequencyUsed{actionId:[{round,turn,at}]}`                                             |                                                                                                  |                                                                                                                                                                                                                                                                         |
| NPC only: `fortify`, `strikes[]`, `npcActions[]`, `skills{}`, `sourceId`, `needsReview` |                                                                                                  |                                                                                                                                                                                                                                                                         |

Ownership of combat-critical stats: HP → system; everything else above → this module. Native NPC fields (AC, saves, perception) are mirrored at import so native initiative, XP and sheets stay consistent; edit them on the starship sheet.
