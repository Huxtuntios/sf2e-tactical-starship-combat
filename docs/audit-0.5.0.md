## Безопасность

- `sheetRoll` принимается только как `true`, `mapChoice` — только `auto|0|1|2`; прочие клиентские опции отбрасываются санитайзером.
- Цель урона фиксируется на стороне ГМ при разрешении атаки; `applyAttackCardDamage` игнорирует цель из запроса.
- Применение урона — только ГМ, ровно один раз (флаг карточки + блокировка в памяти). Бросок урона — только тот, кто может разрешать карточку.
- `userId` берётся из сокета (как и раньше), а не из полезной нагрузки.
