# 0.16.1-dev.1 — незавершённый экспериментальный патч

Основа: коммит `64d13e078b63b27f4778cf0451638c389a520665` (0.16.0). Это не выпуск и не готовое к использованию решение задания. Перед испытанием сохраните резервную копию мира Foundry. Не публиковать сборку без завершения работы и отдельного согласия владельца репозитория.

## Сделано частично

- На листе корабля отображаемые номера Expansion Bay начинаются с 1; сохранённые ID и индексы массивов не изменяются. Миграция для этого отображения не требуется.
- При новом подтверждении GM сохраняются те виды ограничений совместимости и вместимости, которые были обнаружены на момент решения. Уровень и неизвестные данные не подавляются. Для вместимости сохранён её порог, чтобы уменьшение вместимости снова вызвало предупреждение. Старые записи только с `override: true` не содержат сведений о подтверждённых ограничениях: они остаются предупреждениями до повторного выключения и включения override ведущим. Обработка базовых улучшений корпусов пока не реализована.
- Для одного и того же фонового DOM-элемента Sensor Map повторные назначения неизменённых стилей не производятся. Секция зон по-прежнему заменяется при частичных рендерах вместе с фоном. Никаких измерений производительности или установления первопричины тормозов не проводилось; проблему нельзя считать исправленной.
- `writeStarship` сравнивает нормализованное состояние внутри очереди записи GM и не обновляет Actor при отсутствии изменений и дополнительных полей. Это не означает, что все остальные операции и сокеты лишены no-op побочных эффектов. История по-прежнему хранится в GM-whisper сообщениях чата; настройка категорий чата не реализована. Конкурирующие read-modify-write операции в других местах не проверены.

## Не выполнено

Полноценные дроны, станционные действия и улучшения дронов, хранение мин и интеграция Sensor Map; базовые улучшения корпусов; единая настройка чата; полная обработка no-op, синхронизация и конкурентность; профилирование и оптимизация полной замены фонового слоя. Перечень официальных правил дронов не подтверждён полностью: требуемые страницы Archives of Nethys отвечали HTTP 403, хотя отдельные фрагменты доступны поиску. Не следует заменять недостающие правила догадками.

## Проверки и ограничения

`npm run build:packs`, `npm run validate`, `npm run lint`, `npm test` выполнены с Node и mock-окружением; конкретные результаты см. в отчёте передачи. Тесты не подтверждают работу Foundry. Не проводились испытания в Foundry v14, нескольких клиентах, различных размерах изображений, на живой системе SF2e или при использовании дополнительных интеграций. Номера версий в `module.json` — декларации проекта, а не результат проверки в живом мире. Пакет предназначен только для тестового мира; Git commit, push и GitHub Release не выполнялись.
